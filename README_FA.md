# موتور سه‌حالته ورشکستگی مدل‌محور بانک و داشبورد عملیاتی

این مخزن بستهٔ کامل بازتولید نسخهٔ چهارم مقاله است: حل‌گر HJB با مرز جاذب،
موتور پیشنهاد اقدام اصلاحی، تابع جانشین، آزمون همگرایی، داده‌های نمونه، پنل
عمومی شش بانک، ۲۲ آزمون خودکار و داشبورد فارسی آمادهٔ استقرار روی Render.

حالت‌های عملیاتی عبارت‌اند از:

- `w = حقوق مالکانه / حداقل حقوق مالکانه موردنیاز`؛
- `lambda = خالص خروج نقد ۳۰روزه / HQLA = 1/LCR`؛
- `d = مطالبات غیرجاری / تسهیلات ناخالص`.

برخورد با `w=1` یا نبود ترکیب شدنی فروش دارایی/استقراض که قیود LCR و NSFR
را هم‌زمان رعایت کند، رویداد جذب است. نتیجه «احتمال عبور از مرز در مدل» است،
نه اعلام ورشکستگی قانونی، رتبهٔ نظارتی یا توصیه سرمایه‌گذاری.

## خروجی‌های کنترل‌شده

- شبکه تولید: ۲۵×۲۹×۲۳، معادل ۱۶٬۶۷۵ حالت؛
- ۱۷ کنترل فروش دارایی و ۳۰ گام زمانی؛
- احتمال‌ها در بازهٔ صفر تا یک و یکنواختی اقتصادی در ۱۰۰٪ مقایسه‌های مجاور؛
- حل مرجع: ۲۳٬۹۲۵ حالت، ۱۹ کنترل و ۶۰ گام زمانی؛
- جانشین روی داده کنارگذاشته‌شده: RMSE برابر ۰٫۰۲۵۶، `R²=0.9959`،
  `AUC=0.9998` و نرخ منفی کاذب مرزی ۰٫۱۵٪؛
- نتیجه آزمون نرم‌افزار: ۲۲ آزمون از ۲۲ آزمون موفق.

## اجرای محلی

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
pytest -q
python generate_operational_outputs.py
flask --app app run
```

سپس آدرس <http://127.0.0.1:5000> را باز کنید.

## ورودی داشبورد

همهٔ اقلام پولی باید یک واحد مشترک داشته باشند؛ «میلیون ریال» پیشنهاد می‌شود.
داشبورد جمع دارایی، حقوق مالکانه، حداقل سرمایه، HQLA، NCOF، ASF، RSF،
تسهیلات ناخالص، NPL، سقف استقراض و سقف دارایی قابل فروش را می‌گیرد. در حالت
«اختصاصی ظرفیت بانک»، مدل با ظرفیت همان بانک دوباره حل می‌شود و موارد زیر را
برمی‌گرداند:

- احتمال نکول/بقا و ناحیه ایمن، هشدار، ورشکستگی مدل یا بحرانی؛
- نقض سرمایه، LCR، NSFR یا نبود کنترل شدنی؛
- فروش دارایی و استقراض بهینه؛
- کسری فوری HQLA و تأمین مالی باثبات؛
- حداقل تزریق سرمایه، افزایش HQLA، کاهش NCOF یا کاهش NPL برای رسیدن به PD هدف؛
- برنامهٔ ترکیبی کمینه‌تلاش در صورت نبود راه‌حل تک‌اقدامی.

## نقش داده عمومی شش بانک

داده عمومی شامل ۴۸ مشاهده صورت مالی جداگانه برای وبملت، وتجارت، وبصادر،
وپاسار، وپارس و ونوین در سال‌های ۱۳۹۷ تا ۱۴۰۴ است. این داده فقط برای آزمون
ردپای منبع، استخراج، نمودار و منطق نرم‌افزار استفاده می‌شود. صورت مالی سالانه
به‌تنهایی HQLA، NCOF تنش‌یافته، ASF/RSF، NPL، سرمایه نظارتی و PD رسمی را
فراهم نمی‌کند؛ به همین علت پنل عمومی صریحاً «پروکسی» است.
